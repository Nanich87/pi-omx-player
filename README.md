# Raspberry Pi OMXPlayer

**Български** | [English](README.en.md)

Уеб дистанционно за пускане на видеа на телевизор чрез Raspberry Pi.

Raspberry Pi е свързан към телевизора с HDMI и пуска видеата с `omxplayer`. Управлението става от браузъра на телефон, таблет или компютър в същата мрежа, без клавиатура и мишка, вързани към Pi-то.

## За какво е предназначено

За домашен медия център: на Raspberry Pi има папка със сериали или филми и искаш да ги гледаш на телевизора, като ги избираш и управляваш от телефона.

## Възможности

- Списък с видеата от зададена папка, подредени по азбучен ред, с търсене.
- Пускане на видео с едно докосване. Текущото видео се показва най-горе и е маркирано в списъка.
- Спиране на видеото.
- Усилване и намаляване на звука.
- Смяна на аудио пистата (например друг език).
- Смяна, показване и скриване на субтитрите.
- Тъмен интерфейс на български, удобен за телефон. Бутоните остават видими при превъртане, а командите се изпращат без презареждане на страницата.

## Технологии

- **Python 3** и **[Flask](https://flask.palletsprojects.com/)** за уеб сървъра.
- **[omxplayer](https://github.com/popcornmix/omxplayer)** за хардуерно ускорено възпроизвеждане през HDMI. Приложението го управлява, като изпраща клавишите му (`+`, `-`, `j`, `k`, `m`, `q` и т.н.) към неговия стандартен вход.
- **Jinja2** шаблон, **[Bootstrap 5](https://getbootstrap.com/)** и **[Bootstrap Icons](https://icons.getbootstrap.com/)** за интерфейса. Те са включени в проекта (`static/vendor/`), така че приложението работи и без интернет.
- Малко чист JavaScript за търсенето и за изпращане на командите на заден план.

## Изисквания

- Raspberry Pi, свързан към телевизор или монитор с HDMI.
- Raspberry Pi OS с работещ `omxplayer`.
- Python 3 и Flask.

> **Важно:** `omxplayer` вече не се поддържа. Работи на Raspberry Pi OS Buster и на 32-битовия Bullseye с включен legacy графичен драйвер. Не работи на 64-битов Raspberry Pi OS, на Bookworm и на Raspberry Pi 5.

## Инсталация

```bash
sudo apt install omxplayer python3-flask
git clone https://github.com/Nanich87/pi-omx-player.git
cd pi-omx-player
```

## Настройка

В `app.py` задай папката с видеата:

```python
TV_PATH = '/home/pi/videos'
```

По желание можеш да смениш и `HOST` и `PORT` (по подразбиране `0.0.0.0:5000`).

## Стартиране

```bash
python3 app.py
```

След това отвори в браузъра на телефона или компютъра:

```
http://<IP-адрес-на-Pi>:5000
```

IP адреса на Pi-то можеш да видиш с `hostname -I`.

## Сигурност

Приложението няма вход с парола. Всеки в мрежата, който отвори адреса, може да пуска и спира видеа. Използвай го само в доверена домашна мрежа и не го излагай в интернет.
